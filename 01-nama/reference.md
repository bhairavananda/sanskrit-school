|--------|--------|---------|

| -ī | F | devī, nadī |
| -uḥ | M | viṣṇuḥ, vāyuḥ |

## Pronunciation Key

| Symbol | Sound | Example |
|--------|-------|---------|
| ā | long "a" as in "father" | mālā |
| ī | long "ee" | devī |
| ū | long "oo" | pūjā |
| ṛ | a short rolled "ri" | kṛṣṇa |
| ṃ | nasal (anusvāra) | puṣpaṃ |
| ḥ | breath (visarga) | śivaḥ |
| ś | "sh" (palatal) | śiva |
| ṣ | "sh" (retroflex) | viṣṇu |
| ṭ, ḍ, ṇ | retroflex | gaṇeśa |
| c | "ch" as in "church" | candra |
