## Section A: Case Identification

**A1.**
1. śivam → **Dvitīyā** (accusative) — object
2. devāya → **Caturthī** (dative) — for/to
3. gaṅgāyāḥ → **Ṣaṣṭhī** (genitive) or **Pañcamī** (ablative) — of / from
4. mandire → **Saptamī** (locative) — in/on
5. puṣpena → **Tṛtīyā** (instrumental) — by/with

**A2.**
1. Object of worship → **Dvitīyā** (accusative)
2. Subject → **Prathamā** (nominative)
3. Possession → **Ṣaṣṭhī** (genitive)
4. Instrument → **Tṛtīyā** (instrumental)
5. Recipient → **Caturthī** (dative)

## Section D: Sentence Understanding

**D1.**
1. śivaḥ → **Prathamā** (nominative) — subject: "Śiva protects the world"
2. śivam → **Dvitīyā** (accusative) — object: "worships Śiva"
3. śivena → **Tṛtīyā** (instrumental) — "with Śiva"
4. śivāya → **Caturthī** (dative) — recipient: "to Śiva"
5. śivasya → **Ṣaṣṭhī** (genitive) — possession: "of Śiva / Śiva's"

**D2.**
1. **devāya puṣpam dadāmi** (I give a flower to the god)
2. **śivāya namaḥ** (salutation to Śiva)
3. **devasya karuṇā mahatī** (the god's compassion is great)
4. **bhaktaḥ mandire tiṣṭhati** (the devotee stands in the temple)
5. **bhaktyā devīm namāmi** (with devotion I bow to the goddess)

## Section K: Gender Awareness

**K1.**
1. rāma nominative plural: **rāmāḥ** / phala nominative plural: **phalāni**
   — The masculine uses -āḥ, the neuter uses -āni.

2. Because **phala/puṣpa are neuter**, and in all neuter paradigms, the prathamā (nominative) and dvitīyā (accusative) forms are always identical. Masculine stems distinguish subject from object with different endings (-aḥ for nominative vs. -am for accusative).

3. jñāna nominative: Singular: **jñānam** / Dual: **jñāne** / Plural: **jñānāni**

4. madhu nominative singular: **madhu** (neuter -u stems take bare stem form in nominative singular, without the visarga that masculine -u stems have)

5. nadī uses the **-y-** glide (nadyau); vadhū uses the **-v-** glide (vadhvau). This is because the semivowel of -ī is y, and the semivowel of -ū is v.
