**A2.**

4. saṃgama → upa: **sam** + **√gam** (confluence = "go together")

**A3.**
1. √kṛ → **karoti**
2. √gam → **gacchati**
3. √dṛś → **paśyati**
4. √bhū → **bhavati**

## Section B

**B1.**
1. ā + gam → **āgama** (coming, tradition/scripture)
2. sam + gam → **saṃgama** (confluence, meeting)
3. upa + gam → **upagama** (approach)
4. pra + gam → **pragama** (going forth, advance)
5. ni + gam → **nigama** (conclusion, Veda)

**B2.**
1. sam + kṛ → **saṃskāra** / saṃskṛta (refinement, perfected)
2. pra + kṛ → **prakṛti** (nature, primal matter)
3. vi + kṛ → **vikāra** / vikṛti (transformation, distortion)
4. upa + kṛ → **upakāra** (help, service)
5. anu + kṛ → **anukāra** / anukṛti (imitation)

**B3.**
1. graha (seizing) vs. anugraha (grace) — **anu-** adds "following/favoring," transforming seizure into blessing
2. gama (going) vs. āgama (tradition) — **ā-** adds "toward," what has come down to us = scripture
3. krama (step) vs. parikrama (circumambulation) — **pari-** adds "around," stepping around = sacred circling
4. nāma (name/bow) vs. praṇāma (prostration) — **pra-** adds "forth/fully," complete bowing
5. jñāna (knowledge) vs. vijñāna (discernment) — **vi-** adds "special/distinct," knowledge that discriminates

## Section C

**C1.** From √bhaj:
1. Present 3sg: **bhajati**
2. Abstract noun: **bhakti** (devotion)
3. Past participle: **bhakta** (devoted)
4. Action noun: **bhajana** (worship/singing)
5. Agent noun: **bhājaka** (one who serves) or bhakta as agent

**C2.** From √dṛś:
1. Present 3sg: **paśyati**
2. Abstract noun: **darśana** (vision/philosophy)
3. Past participle: **dṛṣṭa** (seen)
4. "Worth seeing": **darśanīya** or **dṛśya**
5. Agent noun: **draṣṭā** (seer)

**C3.**
1. Viṣṇu ← **√viṣ** (to pervade) — "the all-pervading one"
2. Rudra ← **√rud** (to cry/roar) — "the howler/roarer"
3. Īśvara ← **√īś** (to rule) — "the ruler/lord"
4. Hara ← **√hṛ** (to take/remove) — "the remover (of sin/sorrow)"
5. Bhagavān ← **√bhaj** (to share/serve) — "possessor of bhagas (fortune, power, etc.)"

## Section D

**D1.** √hṛ with different upasargas:
1. **ā** + √hṛ = **āhāra** (food — "bringing toward" → intake)
2. **upa** + √hṛ = **upahāra** (offering — "bringing near" → gift)
3. **sam** + √hṛ = **saṃhāra** (destruction — "seizing together" → dissolution)
4. **pra** + √hṛ = **prahāra** (strike — "seizing forth" → blow)

(Also accept: vi+hṛ = vihāra (sport/monastery); pari+hṛ = parihāra (avoidance))

**D2.**
1. yoga, yukta, yuj → **√yuj** — "to join/yoke"; yoga=union, yukta=joined, yuj=to join
2. dāna, datta, dātā → **√dā** — "to give"; dāna=gift, datta=given, dātā=giver
3. stuti, stuta, stauti → **√stu** — "to praise"; stuti=praise, stuta=praised, stauti=he praises

## Section F

**F1.**
1. √yuj (to join) → **yogin** (sub-family: **-in**)
2. √bhaj (to share) → **bhagavat** (sub-family: **-ant/-at**)
3. √bṛh (to expand) → **brahman** (sub-family: **-man**)
4. √rāj (to rule) → **rājan** (sub-family: **-an**)
5. √kṛ (to do) → **karman** (sub-family: **-man**)

**F2.**
1. √man: vowel-stem = **mati** (f, -i stem), consonant-stem = **manas** (n) or **ātman** (m, -an stem)
2. √yuj: vowel-stem = **yoga** (m, -a stem), consonant-stem = **yogin** (m, -in stem)
3. √bhaj: vowel-stem = **bhakti** (f, -i stem), consonant-stem = **bhagavat** (m, -ant stem)
4. √vid: vowel-stem = **vidyā** (f, -ā stem), consonant-stem = **vidvat** (m, -ant stem, "the learned one")
5. √dā: vowel-stem = **dāna** (n, -a stem), consonant-stem = **dātṛ** (m, -tṛ stem, "giver") (also accept: dāyin, -in stem)

## Section J

**J1.** Sample sentences (accept any grammatically correct alternatives):

1. (-in stem): **yogī vanam gacchati** — "The yogin goes to the forest." Or: **gurur yoginam paśyati** — "The teacher sees the yogin." (yoginam = acc sg of yogin)

2. (-ant/-at stem): **bhagavantaṃ naraḥ namati** — "The man bows to the Blessed One." (bhagavantam = acc sg of bhagavat) Or: **bhagavatā dharma uktaḥ** — "Dharma was spoken by the Blessed One." (bhagavatā = inst sg)

3. (-an/-man stem): **ātmani śāntiḥ asti** — "Peace is in the Self." (ātmani = loc sg of ātman) Or: **brahma satyam** — "Brahman is truth." (brahma = nom sg neuter of brahman)

**J2.** Translations:

1. "The yogin meditates on the Self." → **yogī ātmani dhyāyati** (yogī = nom sg of yogin; ātmani = loc sg of ātman; dhyāyati = meditates)

2. "We bow to the Blessed One." → **bhagavantaṃ namāmaḥ** or **bhagavate namāmaḥ** (bhagavantam = acc sg; bhagavate = dat sg; namāmaḥ = we bow; both constructions are valid — √nam takes acc or dat)
