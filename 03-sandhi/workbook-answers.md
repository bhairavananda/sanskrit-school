## Section A: Ac Sandhi (Svara / Vowel Sandhi)

### Yan Sandhi

**A1.**
1. iti + āha = **ityāha** (i + ā → y + ā)
2. madhu + ari = **madhvari** (u + a → v + a)
3. pitṛ + anumatam = **pitranumatam** (ṛ + a → r + a)
4. devī + āgatā = **devyāgatā** (ī + ā → y + ā)
5. su + āgatam = **svāgatam** (u + ā → v + ā)

### Savarṇadīrgha Sandhi

**A2.**
1. mahā + ātmā = **mahātmā** (ā + ā → ā)
2. giri + īśaḥ = **girīśaḥ** (i + ī → ī)

4. vidyā + ālayaḥ = **vidyālayaḥ** (ā + ā → ā)

### Guṇa Sandhi

**A3.**

5. parama + īśvaraḥ = **parameśvaraḥ** (a + ī → e, guṇa)

### Pūrvarūpa and Pararūpa Sandhi

## Section B: Hal Sandhi (Vyañjana / Consonant Sandhi)

### Śchutva and Ṣṭutva Sandhi

**B1.**
1. sat + cit = **sac cit** (sandhi: **Śchutva** -- t → c before c)
2. tat + śrutvā = **tac chrutvā** (sandhi: **Śchutva** -- t → c before ś, ś → ch)
3. rāmas + śete = **rāmaś śete** (sandhi: **Śchutva** -- s → ś before ś)
4. iṣ + taḥ = **iṣ ṭaḥ** (sandhi: **Ṣṭutva** -- t → ṭ after ṣ)
5. tat + ṭīkā = **taṭ ṭīkā** (sandhi: **Ṣṭutva** -- t → ṭ before ṭ)
6. ud + cinoti = **uc cinoti** (sandhi: **Śchutva** -- d → c before c; also jaśtva → chartva context)

---

### Jaśtva Sandhi

**B2.**
1. vāk + īśaḥ = **vāg īśaḥ** (k → g before vowel, 1st → 3rd)
2. tat + eva = **tad eva** (t → d before vowel)
3. jagat + nāthaḥ = **jagad nāthaḥ** (t → d before n, voiced nasal)
4. samrāṭ + jayati = **samrāḍ jayati** (ṭ → ḍ before j, voiced)
5. kakup + antam = **kakub antam** (p → b before vowel)

---

### Anunāsika Sandhi

**B3.**
1. jagat + nāṭyam: Step 1 (jaśtva): t → d → **jagad nāṭyam**; Step 2 (anunāsika): d → n → **jagan nāṭyam** (d is tavarga, nasal = n)
2. vāk + mayam = **vāṅ mayam** (k is kavarga, nasal = ṅ)
3. ṣaṭ + mukhaḥ = **ṣaṇ mukhaḥ** (ṭ is ṭavarga, nasal = ṇ)
4. cit + mayaḥ = **cin mayaḥ** → **chinmayaḥ** (t is tavarga, nasal = n; mandatory since maya is pratyaya)

---

### Anusvāra Sandhi

**B4.**
1. kṛṣṇam + vande = **kṛṣṇaṁ vande** (m → ṁ before v)
2. satyam + vada = **satyaṁ vada** (m → ṁ before v)
3. dharmam + cara = **dharmaṁ cara** (m → ṁ before c)
4. gurum + namati = **guruṁ namati** (m → ṁ before n)
5. rāmam + jayati = **rāmaṁ jayati** (m → ṁ before j)

---

### Parasavarṇa Sandhi

**B5.**
1. saṁ + dhiḥ = **sandhiḥ** (case: **Case 1, padya/internal** -- ṁ → n before dh, tavarga pañcama; mandatory)
2. alaṁ + cakāra = **alañcakāra** (case: **Case 2, pada-anta** -- ṁ → ñ before c, cavarga pañcama; optional)
3. taṁ + daṇḍam = **tandaṇḍam** (case: **Case 2** -- ṁ → n before d, tavarga pañcama; optional)
4. bhagavat + līlā = **bhagavallīlā** (case: **Case 3, torli** -- t → l before l)
5. saṁ + gamaḥ = **saṅgamaḥ** (case: **Case 1/2** -- ṁ → ṅ before g, kavarga pañcama)

---

### Chartva Sandhi

**B6.**
1. samrāḍ + kṛtam = **samrāṭ kṛtam** (ḍ → ṭ before k, voiceless; 3rd → 1st of ṭavarga)
2. jagad + phalam = **jagat phalam** (d → t before ph, voiceless; 3rd → 1st of tavarga)

---

### Mixed Hal Sandhi Identification

**B7.**
1. sac cidam = **sat** + **cidam** (sandhi: **Śchutva** -- t → c before c)
2. jagan nāthaḥ = **jagat** + **nāthaḥ** (sandhi: **Jaśtva** t → d, then **Anunāsika** d → n)
3. kṛṣṇaṁ vande = **kṛṣṇam** + **vande** (sandhi: **Anusvāra** -- m → ṁ before v)

## Section C: Viśeṣa Sandhi (Special / Visarga Sandhi)

### Chatva / Tugāgama Sandhi

**C1.**
1. anu + cheda = **anuccheda** (t-āgama inserted before ch → tch → cch by śchutva)
2. sva + chanda = **svacchanda** (t-āgama → cch)
3. ā + chādayati = **ācchādayati** (t-āgama → cch)
4. pra + channa = **pracchanna** (t-āgama → cch)

---

### Pūrvasavarṇa Sandhi

**C2.**
1. vāg + harati = **vāg gharati** (h → gh, 4th letter of kavarga; optional)
2. dig + hīnaḥ = **dig ghīnaḥ** (h → gh, 4th letter of kavarga)
3. ab + hrasaḥ = **ab bhrasaḥ** (h → bh, 4th letter of pavarga)
4. etat + hi = **etad dhi** (h → dh, 4th letter of tavarga; first jaśtva t → d, then pūrvasavarṇa)

---

### Satva Sandhi

**C3.**
1. mahān + tapasvī: n → s, anusvāra added → **mahāṁs tapasvī** (satva: n → ṁs before t)
2. tān + ca: n → s, anusvāra → ṁs, then s + c → ś (śchutva) → **tāṁś ca**
3. asmin + ṭīkā: n → s, anusvāra → ṁs, then s + ṭ → ṣ (ṣṭutva) → **asmiṁṣ ṭīkā**
4. tān + śūraḥ: n → s, anusvāra → ṁs, then s + ś → ś (śchutva) → **tāṁś śūraḥ**

---

### Visarga Sandhi -- Ukārādeśa

**C4.**
1. rāmaḥ + gacchati = **rāmo gacchati** (aḥ + voiced g → o)
2. bālaḥ + hasati = **bālo hasati** (aḥ + voiced h → o)
3. rāmaḥ + asti = **rāmo'sti** (aḥ + a → o, then a elided with avagraha)
4. eṣaḥ + bālakaḥ = **eṣo bālakaḥ** (aḥ + voiced b → o)

---

### Visarga Sandhi -- Rephādeśa

**C5.**
1. muniḥ + āgataḥ = **munir āgataḥ** (iḥ + ā → r, non-a vowel before visarga)
2. guruḥ + uvāca = **gurur uvāca** (uḥ + u → r)
3. punaḥ + api = **punar api** (avyaya punaḥ + a → r, special case)
4. aśīḥ + yuddham = **aśīr yuddham** (īḥ + y → r)

---

### Visarga Sandhi -- Sakārādeśa

**C6.**
1. rāmaḥ + tatra = **rāmas tatra** (ḥ → s before t, kharaḥ; no further change)
2. namaḥ + te = **namas te** (ḥ → s before t)
3. rāmaḥ + ca = **rāmaś ca** (ḥ → s before c; then s → ś by śchutva)
4. dhanuḥ + ṭaṅkāram = **dhanuṣ ṭaṅkāram** (ḥ → s before ṭ; then s → ṣ by ṣṭutva)

---

### Visarga Sandhi -- Lopa and Jihvāmūlīya

**C7.**
1. devāḥ + vadanti = **devā vadanti** (āḥ + voiced v → ā, visarga lopa)
2. narāḥ + gacchanti = **narā gacchanti** (āḥ + voiced g → ā, visarga lopa)
3. rāmaḥ + karoti = **rāmaḥ karoti** or **rāmaḫ karoti** (visarga remains, or optionally becomes jihvāmūlīya before ka; both forms accepted)

---

### Mixed Visarga Sandhi Identification

**C8.**
1. hariḥ + racayati = **harir racayati** (sandhi: **Rephādeśa** -- iḥ + r (voiced) → r)
2. bālakaḥ + tīkṣṇaḥ = **bālakas tīkṣṇaḥ** (sandhi: **Sakārādeśa** -- ḥ → s before t)
3. bhavataḥ + dṛṣṭam = **bhavato dṛṣṭam** (sandhi: **Ukārādeśa** -- aḥ + voiced d → o)

## Section D: Comprehensive Sandhi Exercises

**D1.**
1. narendraḥ = **nara** + **indraḥ** (sandhi: **Guṇa** -- a + i → e)
2. sadaiva = **sadā** + **eva** (sandhi: **Vṛddhi** -- ā + e → ai)
3. pratyekam = **prati** + **ekam** (sandhi: **Yan** -- i + e → y + e)
4. rāmo'sti = **rāmaḥ** + **asti** (sandhis: **Ukārādeśa** aḥ → o, then **Pūrvarūpa** o + a → o with avagraha)
5. anuccheda = **anu** + **cheda** (sandhi: **Chatva/Tugāgama** -- t-āgama before ch → cch)

**D2.**
1. jagat + nāṭyam:
   - Step 1 (Jaśtva): t → d → jagad nāṭyam
   - Step 2 (Anunāsika): d → n → **jagan nāṭyam**
   - (sandhis: **Jaśtva + Anunāsika**)

2. rāmaḥ + ca + lakṣmaṇaḥ + ca:
   - rāmaḥ + ca: ḥ → s (sakārādeśa), s + c → ś (śchutva) → rāmaś ca
   - lakṣmaṇaḥ + ca: same process → lakṣmaṇaś ca
   - Final: **rāmaś ca lakṣmaṇaś ca**
   - (sandhis: **Sakārādeśa + Śchutva**, applied twice)

3. tat + śrutvā:
   - Step 1 (Śchutva): t + ś → c + ch → **tac chrutvā**
   - (sandhi: **Śchutva**)

4. mahān + śūraḥ:
   - Step 1 (Satva): n → ṁs before ś
   - Step 2 (Śchutva): s + ś → ś + ś
   - Final: **mahāṁś śūraḥ**
   - (sandhis: **Satva + Śchutva**)

5. kṛṣṇam + vande + jagat + gurum:
   - kṛṣṇam + vande: m → ṁ (anusvāra) → kṛṣṇaṁ vande
   - jagat + gurum: t → d (jaśtva) → jagad gurum (or optionally jagan gurum with anunāsika, but g is not nasal, so jaśtva only) → jagad gurum
   - Final: **kṛṣṇaṁ vande jagad gurum**
   - (sandhis: **Anusvāra + Jaśtva**)
