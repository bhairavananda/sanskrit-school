# 16 — Prefixes (Upasargas) and Key Suffixes

Source key: DM = Devī Māhātmyam, LS = Lalitā Sahasranāma, KKS = Kakārādi Kālī SN, KS = Kālī SN, VS = Viṣṇu SN

---

## A. Upasargas (Verbal Prefixes) — with Text Examples

| Prefix | Meaning | Example | Source |
|--------|---------|---------|--------|
| pra- | forward, intensely, forth | prahāra (strike), praṇamya (prostrate), prabodhana (awakening) | DM 1.73, 3.24; VS passim |
| vi- | apart, away, intensely | vicchinna (severed), vināśa (destruction), vimukta (freed) | DM 3.18; LS passim |
| sam- | together, completely | saṃhāra (annihilation), saṃgrāma (battle), saṃpūjya (worshipping fully) | DM 3.26; LS passim |
| upa- | near, toward, sub- | upāgamya (having approached), upāsana (worship) | DM passim; VS passim |
| ā- | toward, until | āgata (arrived), ākarṇya (hearing), ākṛṣya (dragging) | DM 6.2, 6.4 |
| ni- | down, into, completely | nipāta (downfall), nihata (slain), nilaya (abode) | DM passim; LS passim |
| nis- / nir- | out, without, away | nirgata (gone out), nirghāta (thunder), nirañjana (unstained) | DM 9.26; LS 134 |
| abhi- | toward, against, upon | abhyadhāvat (rushed toward), abhiṣeka (consecration) | DM 6.13; KS passim |
| pari- | around, fully | parivṛta (surrounded), parikṣipta (encircled) | DM passim; LS passim |
| anu- | after, along, according to | anugraha (grace), anucara (follower) | LS 272; DM passim |
| ati- | beyond, exceedingly | ativīrya (of great valor), atimatta (extremely intoxicated) | DM 2.57; KS passim |
| ud- / ut- | up, out | utthitā (risen), udgata (arisen), unmatta (mad) | DM passim; KS passim |
| apa- | away, off | apavarga (liberation), apamṛtyu (untimely death) | DM 13.5, 12.19 |
| dur- / duṣ- | bad, difficult | durgā (inaccessible), durlabha (hard to get), durjaya (hard to conquer) | DM 4.11; LS 188; KS passim |
| su- | good, well, easy | sundara (beautiful), sulabha (easy to attain), sukha (happiness) | LS passim; KS passim |

## B. Feminine Name-Forming Suffixes (common in sahasranāmas)

| Suffix | Function | Examples | Sources |
|--------|----------|----------|---------|
| -ā | basic feminine | durgā, kālī, ambikā, śivā | all texts |
| -inī | possessive feminine | yoginī, kāminī, vāsinī, dhāriṇī | LS/KKS/KS passim |
| -ikā | diminutive/descriptive feminine | kālikā, caṇḍikā, nāyikā | DM passim; KS passim |
| -iṇī | agent feminine | pāśinī, śūlinī, cakriṇī | KS passim |
| -vatī | possessing (feminine) | kalavatī, bhagavatī, guṇavatī | KKS 6; DM passim; KS passim |
| -mayī | made of, consisting of (f.) | cinmayī, sarvamayī, ānandamayī | LS 251; DM 11.23; KS passim |
| -rūpiṇī | having the form of (f.) | caitanyarūpiṇī, kāmarūpiṇī | DM 5.14; KKS passim; KS passim |
| -svarūpiṇī | whose essential nature is (f.) | mantrarūpiṇī, sarvasvarūpiṇī | KS passim; DM 11.6 |
| -parāyaṇā | devoted to (f.) | kāmaparāyaṇā, dharmaparāyaṇā | KKS passim; KS passim |
| -priyā | fond of (f.) | puṣpapriyā, madhupriyā | KKS passim; LS passim |
| -sthā / -sthitā | situated in (f.) | bindumaṇḍalavāsinī, padmasthā | LS passim; KKS passim |
| -dā / -dāyinī | giving (f.) | varadā, abhayapradā, siddhidāyinī | LS passim; KKS passim |

## C. Key Kṛt Suffixes (participles/verbal adjectives)

| Suffix | Function | Examples | Sources |
|--------|----------|----------|---------|
| -ta (pp.) | past passive participle | hata (slain), kṛta (done), stuta (praised) | all texts |
| -tavat (past active pp.) | one who has done | kṛtavān, dṛṣṭavān | DM passim |
| -māna (pres. middle pp.) | being done | stūyamāna (being praised) | DM 4.37 |
| -at / -ant (pres. active pp.) | doing | gacchat, kurvat, jayat | DM passim |
| -tṛ / -tr (agent) | doer | kartṛ, hartṛ, goptrī | LS 266; VS passim |
| -tvā (absolutive) | having done | hatvā, dṛṣṭvā, śrutvā, gatvā | DM throughout |
| -ya (absolutive with prefix) | having done (w/ prefix) | praṇamya, ākarṇya, samīkṣya | DM throughout |
| -ana (action noun) | the act of | vandana, tarpaṇa, pūjana | KKS passim; VS passim |
| -in (possessive) | having, possessing | tejasvín, tapasvin, yogin | VS passim; KS passim |
