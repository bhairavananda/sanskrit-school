# Vocabulary Bank — Index

A comprehensive Sanskrit vocabulary bank drawn from five foundational texts. Every entry includes source references so you can trace each word back to its original verse or name.

## Source Texts

| Abbreviation | Text | Tradition |
|---|---|---|
| **DM** | Devī Māhātmyam (Durgā Saptaśatī, 700 verses, 13 chapters) | Śākta / Mārkaṇḍeya Purāṇa |
| **LS** | Lalitā Sahasranāma (1000 names, Brahmāṇḍa Purāṇa) | Śrīvidyā |
| **KKS** | Kakārādi Kālī Sahasranāma (1000 names, Rudrayāmala) | Kālī-kula |
| **KS** | Kālī Sahasranāma (1000 names, Bṛhannīla Tantra) | Kālī-kula |
| **VS** | Viṣṇu Sahasranāma (1000 names, Mahābhārata Anuśāsana Parva) | Vaiṣṇava |

## Reference Format

Each entry shows: **word** — meaning — [grammar] — Sources: DM 2.14, LS 45, VS 100, etc.

- DM references = chapter.verse (e.g., DM 1.78 = Ch.1, verse 78)
- LS/KKS/KS/VS references = name number (e.g., LS 264 = 264th name)
