# Svara-Vidyā — Reference Guide

## The Three Svaras

| Svara | Pitch | KYV Mark | Position | Symbol |
|-------|-------|----------|----------|--------|
| **Udātta** | High / raised | Unmarked | The peak syllable of a word | (none) |
| **Anudātta** | Low / depressed | Underline below | All syllables before the rise | \_ |
| **Svarita** | Falling | Vertical bar above | Immediately after udātta | \| |

## Svara Determination Rules

| Rule | Description | Example |
|------|-------------|---------|
| One udātta per word | Each word has exactly one udātta syllable | agním: "gni" is udātta |
| Svarita follows udātta | The syllable after udātta becomes svarita | agnínā: "ná" is svarita after "gní" |
| Anudātta = default | Everything not udātta or svarita | Multiple syllables may be anudātta |
| Verb-accent loss | Finite verbs in main clauses lose udātta | bhávati (independent) vs bhavati (in clause) |
| Compound accent | In most compounds, first member loses accent | rāja + puruṣa → rājapúruṣa |

## Svarita Subtypes

| Type | Name | When It Occurs |
|------|------|---------------|
| Jātya | Natural | Within a word, on the syllable after udātta |
| Kṣaipra | Quick | When a long svarita vowel shortens before another vowel |
| Abhinihita | Absorbed | When a svarita vowel merges with the following vowel |
| Kampa | Trembling | Enclitic svarita at word-boundaries — wavering pitch |
| Praślișṭa | Merged | When svarita results from vowel-coalescence in sandhi |

## KYV Notation Compared to Other Śākhās

| Tradition | Udātta | Anudātta | Svarita |
|-----------|--------|----------|---------|
| **Kṛṣṇa Yajurveda** | Unmarked | Underline below | Vertical bar above |
| **Ṛgveda** | Vertical bar above | Unmarked | Double bar / horizontal above |
| **Śukla Yajurveda** | Similar to KYV | Similar | Similar |
| **Sāmaveda** | Number system (1-7) for musical notes | — | — |

Note: The Sāmaveda extends the three-svara system into a full musical scale — this is the bridge between Vedic recitation and Indian music (sāmagāna).

## Saṃhitā, Pada, and Vikṛtis

### Recitation Forms — Complete Table

| Form | Pattern | Example (words: A B C D) | Redundancy |
|------|---------|--------------------------|-----------|
| **Mūla** (saṃhitā) | ABCD | Continuous, with sandhi | None |
| **Pada** | A \| B \| C \| D | Word-by-word, sandhi dissolved | None |
| **Krama** | AB BC CD | Overlapping pairs | Each word appears 2× |
| **Jaṭā** | AB BA AB, BC CB BC | Forward-back-forward per pair | Each word appears 6× |
| **Śikhā** | AB BA AB+C | Jaṭā + next word appended | — |
| **Rekhā** | AB BA AB, BC CB BC... | Like jaṭā, continuous | — |
| **Dhvaja** | End-to-start patterns | Complex reverse | — |
| **Daṇḍa** | Linear combinations | — | — |
| **Ratha** | Chariot-wheel pattern | — | — |
| **Ghana** | AB BA ABC CBA ABC | Triple weave | Each word appears 10×+ |

### Building Krama from Saṃhitā

Source: *namaḥ somāya ca rudrāya ca*

Words: (1) namaḥ (2) somāya (3) ca (4) rudrāya (5) ca

```
Krama:
namaḥ somāya    (1-2)
somāya ca       (2-3)
ca rudrāya      (3-4)
rudrāya ca      (4-5)
ca iti ca        (5-end marker)
```

### Building Jaṭā from Pada

```
Jaṭā:
namaḥ somāya — somāya namaḥ — namaḥ somāya
somāya ca — ca somāya — somāya ca
ca rudrāya — rudrāya ca — ca rudrāya
rudrāya ca — ca rudrāya — rudrāya ca
```

### Building Ghana from Pada

```
Ghana:
namaḥ somāya — somāya namaḥ — namaḥ somāya ca — ca somāya namaḥ — namaḥ somāya ca
somāya ca — ca somāya — somāya ca rudrāya — rudrāya ca somāya — somāya ca rudrāya
ca rudrāya — rudrāya ca — ca rudrāya ca — ca rudrāya ca — ca rudrāya ca
...
```

Pattern formula: AB BA ABC CBA ABC (then shift by one word and repeat)

## The Six Factors of Śikṣā

| # | Factor | Sanskrit | Controls | Where Learned |
|---|--------|----------|----------|---------------|
| 1 | **Varṇa** | वर्ण | Which sound (identity) | Varṇa-Vidyā |
| 2 | **Svara** | स्वर | Which pitch (accent) | This stage |
| 3 | **Mātrā** | मात्रा | How long (duration) | Chandas I |
| 4 | **Bala** | बल | How much force (prāṇa) | Practice |
| 5 | **Sāma** | साम | How smooth (melody/flow) | Practice |
| 6 | **Santāna** | सन्तान | How sounds connect (junction) | Sandhi rules |

## Svara vs Chandas — Two Independent Dimensions

| | Chandas (meter) | Svara (accent) |
|---|---|---|
| **Measures** | Syllable weight | Syllable pitch |
| **Values** | Laghu / guru | Udātta / anudātta / svarita |
| **Used in** | Classical + Vedic | Vedic only |
| **Still active** | Yes (all poetry) | Only in Vedic recitation |
| **Determines** | Meter pattern | Meaning / mantra direction |
| **Independence** | A syllable can be laghu+udātta, guru+anudātta, etc. | |

## Key Prātiśākhya Terms

| Term | Meaning | Relevance |
|------|---------|-----------|
| **Saṃhitā** | "Placed together" — continuous text with sandhi | The recited form |
| **Pada** | "Word/foot" — separated text without sandhi | The analytical form |
| **Vikṛti** | "Modification" — rearranged recitation pattern | Jaṭā, ghana, etc. |
| **Prakṛti** | "Natural form" — saṃhitā, pada, krama (the three "natural" forms) | Baseline recitations |
| **Sthāna** | "Place" — point of articulation | From Varṇa-Vidyā |
| **Prayatna** | "Effort" — manner of articulation | From Varṇa-Vidyā |
| **Pluta** | "Extended" — 3-mātrā vowel (tripled duration) | Rare; used in calling |
| **Kampa** | "Trembling" — wavering pitch at word-junctions | Enclitic svarita |
| **Avagraha** | "Separation" — the mark showing elided "a" in sandhi | Written as ' (apostrophe) |
