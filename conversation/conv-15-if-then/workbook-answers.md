# Stage 15: If & Then — Workbook Answers

---

## Section A: Translate to Sanskrit

1. yadi tvaṃ śvaḥ āgacchasi tarhi vayaṃ krīḍāmaḥ.
2. yadi ahaṃ dhanavanān syām tarhi viśvaṃ paryaṭeyam.
3. yadi ācāryaḥ pṛcchati tarhi satyaṃ vada.
4. yadi jalaṃ na bhavati tarhi vanaspatayaḥ mriyante.
5. śīghraṃ gaccha, nocet vilambitaḥ bhaviṣyasi.

---

## Section B: Translate to English

1. If you drink water, then health comes (you become healthy).
2. If she were to come, then we would listen to a story.
3. If there is wealth, then give charity.
4. If I were a bird, I would see the Himalayas.
5. Study quickly, otherwise you will not pass the exam.

## Section D: Sample Mini-Dialogues

**1. Flying vehicle:**

— yadi āvayoḥ vimānaṃ syāt tarhi kutra gaccheva?
  If we had a flying vehicle, where would we go?

— yadi mama vimānaṃ syāt tarhi pratidinṃ himālayam uḍḍayeyam.
  If I had a flying vehicle, I would fly to the Himalayas every day.

— aham api! megheṣu upari viśrāmaṃ kuryām.
  Me too! I would rest above the clouds.

— yadi tathā syāt tarhi jīvanaṃ sundararṃ syāt!
  If that were so, life would be beautiful!

**2. Parent and child:**

— yadi śākāni na khādasi tarhi balavān na bhaviṣyasi.
  If you don't eat vegetables, you won't be strong.

— kintu mama phalāni rocante! yadi phalāni khādāmi tarhi api balavān bhavāmi, nanu?
  But I like fruits! If I eat fruits, I become strong too, right?

— ām, phalāni api uttamāni. kintu śākāni api khāda, nocet rogaḥ bhaviṣyati.
  Yes, fruits are good too. But eat vegetables also, otherwise illness will come.

— yadi tvaṃ miṣṭānnaṃ dadāsi tarhi śākāni api khādāmi!
  If you give sweets, then I'll eat vegetables too!

## Section E: Sample Responses

**1. Living in another time:**

yadi ahaṃ prācīnakāle vaseyyam tarhi nalandā-viśvavidyālaye paṭheyam. yadi tatra guravāḥ syuḥ tarhi vyākaraṇaṃ jyotiṣaṃ ca adhīyīya. yadi kālidāsasya samaye syām tarhi tena saha kāvyaṃ vicārayeyam. tat tu svapnaḥ eva syāt, kintu sundaraḥ svapnaḥ!

(If I lived in ancient times, I would study at Nalanda University. If there were teachers, I would learn grammar and astronomy. If I were in Kalidasa's time, I would discuss poetry with him. That would just be a dream, but a beautiful dream!)

**2. Indicative vs. optative:**

*Yadi saḥ gacchati* uses the indicative mood — the speaker considers it a real possibility that "he goes." *Yadi saḥ gacchet* uses the optative — the speaker is imagining a hypothetical or unlikely scenario, "if he were to go." The first is for practical conditions you expect might happen; the second is for wishes, speculations, or unreal situations.
