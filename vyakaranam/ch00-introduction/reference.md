# Chapter 0: Introduction — Reference Guide

## Course Structure Overview

| Chapter | Topic | Sanskrit Term | Description |
|---------|-------|---------------|-------------|
| 1 | Letters & Sounds | Varna-vicara | Alphabet, svara, vyanjana classification |
| 2 | Euphonic Combination | Sandhi | Rules for joining sounds at word boundaries |
| 3 | Pronouns | Sarvanama | Declension of pronouns (yad, tad, kim, idam) |
| 4 | Verb Forms | Kriyapada | Conjugation across tenses (lat, lrt, lot, lang, vidhiling) |
| 5 | Compounds | Samasa | Tatpurusa, dvandva, bahuvrihi, avyayibhava |

## Key Terms Introduced

| Term | Meaning |
|------|---------|
| Vyakaranam (व्याकरणम्) | Grammar; analysis of language |
| Varna (वर्ण) | Letter, sound unit |
| Sandhi (सन्धि) | Euphonic combination of sounds |
| Sarvanama (सर्वनाम) | Pronoun |
| Kriyapada (क्रियापदम्) | Verb form |
| Samasa (समास) | Compound word |
| Sabda-rupa (शब्दरूप) | Noun/pronoun declension table |
| Dhatu-rupa (धातुरूप) | Verb conjugation table |
| Svara (स्वर) | Vowel |
| Vyanjana (व्यञ्जन) | Consonant |
| Vedanga (वेदाङ्ग) | Limb of the Veda (grammar is one of six) |
| Panini (पाणिनि) | The great grammarian, author of the Astadhyayi |
