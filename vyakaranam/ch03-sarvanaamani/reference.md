# Chapter 3: Sarvānāmāni — Reference Guide

## Quick Overview of Major Pronouns

| Pronoun | Meaning | Type |
|---------|---------|------|
| tad | that, he/she/it | Demonstrative |
| etad | this (near) | Demonstrative |
| idam | this | Demonstrative |
| adas | that (remote) | Demonstrative |
| yad | who, which | Relative |
| kim | who? what? | Interrogative |
| asmad | I, we | Personal (1st person) |
| yuṣmad | you | Personal (2nd person) |
| sarva | all, every | Universal |
| viśva | all, entire | Universal |
| ubhaya | both | Universal |
| anya | other | Indefinite |
| eka | one | Numeral-pronominal |
| sva | own, self | Reflexive |

## Pronominal vs. Regular Declension — Key Differences

| Vibhakti | Regular -a (deva) | Sarvānāma (sarva) |
|----------|-------------------|-------------------|
| Caturthī sg. | devāya | sarvasmai |
| Pañcamī sg. | devāt | sarvasmāt |
| Saptamī sg. | deve | sarvasmin |
| Prathamā N. sg. | — | sarvam (not sarvaḥ) |

Words that follow this sarvānāma pattern: sarva, viśva, ubhaya, eka, anya, anyatara, itara, pūrva, para, avara, dakṣiṇa, uttara, apara, adhara, sva.

## Enclitic Forms — Quick Reference

Enclitic (shortened) forms of asmad and yuṣmad cannot begin a sentence.

| Person | Dvitīyā | Caturthī | Ṣaṣṭhī |
|--------|---------|----------|---------|
| asmad sg. | mā | me | me |
| asmad dv. | nau | nau | nau |
| asmad pl. | naḥ | naḥ | naḥ |
| yuṣmad sg. | tvā | te | te |
| yuṣmad dv. | vām | vām | vām |
| yuṣmad pl. | vaḥ | vaḥ | vaḥ |
