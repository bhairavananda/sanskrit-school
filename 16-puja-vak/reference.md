# Pūjā-Vāk — Reference Guide

## Saṅkalpa Template

```
[Time — locative]
[Place — locative]
[Performer — nominative]
[Deity — genitive]
[Purpose — dative / artham compound]
[Rite — accusative]
[Verb — kariṣye (lṛṭ, first person)]
```

## Dhyāna-Śloka Grammar Patterns

### Bahuvrīhi Template
**[modifier]-[body-part/attribute] + ām/am** = "she/he who has [modifier] [body-part]"

| Compound | Analysis | Translation |
|----------|----------|-------------|
| trinayanām | tri + nayana + ām | "Her who has three eyes" |
| caturbhujam | catur + bhuja + am | "Him who has four arms" |
| sindūrāruṇa-vigrahām | sindūra-aruṇa + vigraha + ām | "Her whose form is vermillion-red" |
| smitamukhīm | smita + mukhī + m | "Her whose face is smiling" |
| nīlakaṇṭham | nīla + kaṇṭha + am | "Him whose throat is blue" |
| padmahastām | padma + hasta + ām | "Her whose hand holds a lotus" |
| jaṭāmukuṭa-maṇḍitam | jaṭā-mukuṭa + maṇḍita + am | "Him adorned with a crown of matted locks" |

## Āvaraṇa Bīja Progression

| # | Āvaraṇa Name | Bīja | Derivation Principle |
|---|-------------|------|---------------------|
| 1 | Trailokyamohana | aṃ āṃ sauḥ | Base vowels + śakti-bīja |
| 2 | Sarvāśāparipūraka | aiṃ klīṃ sauḥ | Bālā mantra (the base triad) |
| 3 | Sarvasaṃkṣobhaṇa | hrīṃ klīṃ sauḥ | hrīṃ enters (māyā replaces vāk) |
| 4 | Sarvasaubhāgyadāyaka | haiṃ hklīṃ hsauḥ | h- prefix (Śiva's breath enters each) |
| 5 | Sarvārthasādhaka | hsaiṃ hsklīṃ hssauḥ | hs- prefix (full haṃsa permeates) |
| 6 | Sarvarakṣākara | hrīṃ klīṃ bleṃ | Pattern breaks (bleṃ = grounding) |
| 7 | Sarvarogahara | hrīṃ śrīṃ sauḥ | klīṃ → śrīṃ (desire → fullness) |
| 8 | Sarvasiddhiprada | hsaiṃ hsklīṃ hssauḥ | Mirrors 5th (haṃsa returns) |
| 9 | Sarvānandamaya | Full Pañcadaśī | All compressions expand |

### h-infusion = Śiva entering Śakti bījas
- No prefix = Śakti alone
- h- = Śiva breathing into each bīja
- hs- = full haṃsa (Śiva + Śakti) permeating
